The librarian

Nalanda Worker

Checks your MCP token, runs tools, and coordinates the bound services. It has three entry points: an HTTP request, a queue message, or a scheduled event. It does not need a permanently running server on your Mac.

worker.ts → fetch / queue / scheduled

Bindings are named connections available to the code, such as env.DB and env.AI. They are services—not separate processes you start on your Mac.

What is a Worker, really?

A deployed JavaScript/TypeScript program that Cloudflare runs when an event arrives. You deploy code; Cloudflare operates the execution infrastructure.

Your agent asks a question.

An authenticated MCP call reaches the Worker over HTTPS. The fetch handler checks credentials, dispatches a tool, and returns structured results.

agent → HTTPS /mcp\nWorker.fetch(request, env)\n→ nalanda_search → evidence

Workers uses lightweight isolated runtimes. Cloudflare may reuse a runtime; in-memory values are not a durable database or a reliable record of progress.

What outlives the event?

The library’s records.

D1 keeps documents, timestamps, checkpoints and job state. Vectorize keeps derived embeddings. Queues delivers background work. The program can return while that work continues.

Search usually returns evidence directly. Hydration returns a job ID so the client does not wait for a whole browser scan.
Execution

A Worker handles events. It is not a Mac terminal left running overnight.

Persistence

A durable service keeps state. Local variables may disappear between invocations.

A different product

Cloudflare Workflows is a separate service. Nalanda currently uses Queues and D1 checkpoints, not Workflows.

    CAPTURE · STEP 1 OF 6

    Fetched, ingested and indexed are separate milestones. A completed source scan can still be partial, or its captured records can still be waiting for ingestion and embeddings.

    Meaning becomes a list of numbers.

    EmbeddingGemma maps a passage into a vector: numbers that help compare meaning. Your question goes through the same model so similar passages can be found.

    300M MODEL · 512 DIMENSIONS
    A vector, close up
    [0.08, −0.03, 0.12, …] · invented values for illustration

    A dimension is one numeric coordinate—not a named topic, a word, or a database column you browse. The learned coordinates work together. You cannot label coordinate 17 “AI” and coordinate 18 “travel.”

    Cloudflare’s model produces 768 coordinates. Nalanda takes the first 512 using the model’s Matryoshka representation, then normalizes the vector to unit length. More dimensions use more space; they do not automatically guarantee better results.

    A long README becomes multiple overlapping passages: up to 1,600 characters each, with 200-character overlap. Vector capacity counts passages, not saved posts.

    FREE TIER · BOUNDED WORK
    NORMAL PROCESSING

    Capture, then index.

    Queue consumers process bounded source pages, imports and embedding batches. D1 records progress so the next step can continue. Search reads the archive independently of the current source scan.

    capture → import queue → D1 → embedding queue → Vectorize
    Browser constraint

    10 minutes / day

    The provider’s free browser time is account-wide. Nalanda separately caps starts at six per UTC day, paces them, and closes bounded sessions. Quota availability is not guaranteed.

    Daily hydration

    06:45 IST

    The daily cron runs at 01:15 UTC. Recovery runs every ten minutes. They execute in the cloud even when your Mac is asleep.

    What “free” means

    Wait at a limit.

    Nalanda has no paid fallback or automatic plan upgrade. Free allowances still limit throughput and storage; they do not promise unlimited operation.

    What is kept—and what is not.

    • D1: captured text, source URLs, timestamps and provenance, inferred summaries/tags, durable jobs and checkpoints.
    • Vectorize: derived passage embeddings and limited metadata. Source text is recovered from D1.
    • Worker secrets: the MCP token and authorized X/Instagram session cookies. Credentials stay out of Git and teaching examples.
    • Transient: browser pages and processing buffers. This pipeline does not retain videos, audio, HTML captures, screenshots or verbatim speech transcripts.
    Current boundaries of the project
    • Instagram scans loaded AI-collection links and reports partial coverage. Full collection pagination and speech/OCR extraction are not implemented.
    • GitHub refresh reads public stars and READMEs; private refresh requires separate authorization.
    • Agents can submit evidence-based, keyword-heavy summaries and tags. No paid JEV or OpenRouter inference is required by the cloud pipeline.
    • First-seen time is not necessarily save time. Dates carry provenance; old captures remain archived after unsave or unstar.
    • Auth checks access, not the truth of a post. Retrieved content is untrusted evidence, never an instruction to execute.
    • October 12 verification: X and search worked. GitHub’s bounded test worked after quota errors. Instagram’s account-detection fix was deployed, but successful cloud capture was still unverified.
